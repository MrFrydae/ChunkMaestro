[Machine-readable rows](requirements-data.json) contain source line numbers, answer digests, unique acceptance IDs, components, milestones, scope and evidence. Scope is independent of status: required = selected delivery; constraint = invariant/exclusion within a selected feature; conditional = selected capability requiring detected integration/authority; inventory = recorded fact requiring revalidation; unresolved = decision-dependent; excluded = expressly outside current delivery. Mixed questions retain all limits in their acceptance case. There is no claim of universal platform support. [Capability matrix](capability-matrix.md) refines platform gates; [decisions](open-decisions.md) isolate blocked slices; [architecture](../architecture/README.md) and [threat model](../security/threat-model.md) define proposed boundaries.

Later owner overlay: [explicit C# types everywhere](../architecture/README.md#later-owner-policy-explicit-c-types), including production/tests/checked-in generated code. This supplements the fixed 205-ID baseline; it does not invent Q206 or claim lead-owned analyzer enforcement is complete.

A milestone is the row's final acceptance checkpoint; earlier foundations can ship independently.
